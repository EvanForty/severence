# SEVERENCE

Hold with conviction. Exit with protection.

A Solana launchpad where every trade funds SOL rewards for holders and a protection reserve that covers part of a losing exit.

## Files

- `index.html` — the full site (single file, styles and scripts inline)
- `logo.png` — the SEVERENCE logo

## Run locally

Open `index.html` in a browser. No build step.

## Deploy

Works as-is on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
